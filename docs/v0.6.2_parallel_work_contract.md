# v0.6.2 병렬 작업 계약

> 역사적 v0.6.2 계약이다. 아래 동결·종료·main 제한은 해당 revision에만 적용한다. v0.6.2.1 Fusion 유예는 `fusion_deferred_policy_v0.6.2.1_ko.md`, 현재 상태와 승인 경계는 `final/release_notes_v1.0.0-rc1_ko.md`를 따른다.

- revision: `parallel-actuation-hardening-v0.6.2`
- architecture: `FROZEN`
- implementation: `ACTUATION_HARDENING_CANDIDATE`
- virtual process: `VALIDATED_WITHIN_REDUCED_ORDER_SCOPE`
- Fusion baseline: `V0.6.1_IMMUTABLE`
- Fusion/cross-solver: `PENDING_EXTERNAL_EXECUTION`
- procurement: `USER_APPROVAL_REQUIRED`

v0.6.2는 기계 형상·재료·Fusion 하중/접촉/구속을 바꾸지 않는다. 허용 변경은 펌웨어, shadow namespace, 공정위험 screening, Fusion 결과 consumer, BOM conditional allowance와 문서다. `analysis/fusion_delta_queue/change_classification.csv`와 validator가 이 경계를 검사한다.

외부 Fusion 결과가 없으므로 main promotion은 금지한다. 당시 허용 종료 상태는 `ACTUATION_HARDENING_COMPLETE`와 `FUSION_RESULT_INTEGRATION_PENDING`의 조합뿐이다. 구매·가공·energization은 수행하지 않는다.
