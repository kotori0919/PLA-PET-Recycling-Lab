# Hot-zone 소재·가공 확인 요청서 — JLCCNC 부적합 회신 / 대체 공급자 HOLD

대상: EX-BAR-01 배럴, EX-SCR-01 스크루 및 별도 유지판 후보.
JLCCNC는 2026-09-08 회신에서 비목록 SCM440 조달, Q&T 및 가스질화가 불가하다고
확인되어 현 사양의 완결 공급 후보에서 제외했다. 아래 요구는 대체 전문 업체용이다.
목적: v0.8의 실제 온도·하중 모델에 사용할 근거 확보. 견적 승인·발주서가 아니다.
첨부 요구사항 §3.3의 regional non-singular SF≥2 및 센서 보어/다이 접합부
검증을 위해 필요하다. 현재 공개 상온 강도나 뜨임 온도 표만으로는 충족되지 않는다.

## 배럴·스크루 공급자에게 확인할 내용

### JLCCNC 공개 안내 대조

2026-09-08 재확인에서 [공식 CNC 설비 안내](https://jlc3dp.com/help/article/what-jlc3dp-has-for-cnc-machining-facility)는
선삭·밀링 장비가 일반적인 steel을 가공한다고 설명한다. 반면
[JLCCNC 공식 가공능력 페이지](https://jlccnc.com/capabilities/cnc-machining-service)의
표준 steel alloy 목록은 45# steel만 명시한다. 별도 공식 기술 글은 4140 pre-hard를
일반 가공 예로 들지만 주문 가능한 표준 소재라는 보증은 아니다. 어느 페이지도
SCM440/4140의 실제 공급 상태, QT 경도, 질화 공정,
또는 245–270°C 최종 처리재 물성을 보증하지 않는다. 이후 서면 회신으로 불가가
확정됐으므로 JLCCNC는 EX-BAR-01/EX-SCR-01의 공급 후보에서 제외한다.

추가 공개자료 확인: [표면처리 서비스 안내](https://jlccnc.com/help/article/surface-treatment-for-cnc-machining)
(페이지 갱신 2026-03-23)의 공정 목록에서는 질화를 확인하지 못했다.
[열처리 설명 글](https://jlccnc.com/blog/heat-treatment-metal-cnc)
(2026-02-27 게시, 2026-03-06 갱신)은 일반적인 열처리와 가공 순서를 설명하지만
본 배럴의 SCM440 QT·질화 수락이나 고온 물성 성적서는 아니다.
JLCCNC에 대한 사전 검토는 서면 회신으로 종료했다. 대체 업체가 외주 열처리 경로를 제안한다면
수행 업체와 lot 추적·최종 검사 책임까지 확인해야 한다.

대체 업체 확인 문안:
“SCM440 배럴·스크루의 지정 QT 및 질화, 열처리 후 정밀 마감을 일괄 수행하거나
추적 가능한 외주 공정으로 제공할 수 있습니까? 가능하다면 실제 공급 강종·규격,
열처리 수행 주체와 최종 성적서 범위를 알려주십시오. 245–270°C에서 적용 가능한
최종 처리 상태의 물성 근거 제공 여부도 구분해 주십시오. 현재 문의는 가공 가능성
확인용이며 대체재 승인·견적 수락·발주가 아닙니다.”

[공식 소재 안내의45# steel 페이지](https://jlccnc.com/help/article/steel-45-cnc-machining)는
확인했지만 해당 공개 페이지와 후속 회신 모두 SCM440 지정 QT+질화 공급을 입증하지
못했다. JLCMC 카탈로그의SCM440 기어 판매는
JLCCNC 맞춤 배럴 공정 수락과 별개다. 45# steel을SCM440 대신 자동 선택하지 않는다.

[JLCCNC 설계 가이드](https://jlccnc.com/help/article/cnc-machining-design-guideline)는
공차 미기재 시±0.1 mm 또는 그 이상 표준공차를 안내하고 별도 공차는2D 도면에
명시하도록 요구한다. 나사 종류·깊이와 날카로운 내부 모서리도 명시해야 한다.
따라서 키홈6.005–6.010 mm 후보, 적층 정렬, 센서 홀의 바닥 형상 및 최종 열처리
뒤 치수는 STEP 업로드만으로 보증된다고 간주할 수 없다. 아래 자료와 함께
해당 공정 수락 여부를 대체 업체에 확인해야 한다. 견적 수락·발주·생산 승인은 하지 않았다.

| 확인 항목 | 필요한 자료 | 채택 조건 |
|---|---|---|
| 소재 식별 | 적용 규격, 강종, heat/lot, 소재 검사 성적서 | SCM440와 실제 공급품의 연결 확인; 유사 강종 자동 대체 금지 |
| QT 상태 | 담금질·뜨임 온도/시간/냉각, 처리 시 단면, 최종 경도 범위 | 가공 후 실제 단면과 열처리 순서가 추적 가능할 것 |
| 질화 상태 | 공정 온도/시간, 유효층 깊이 기준, 화합물층, 최종 심부 경도 | QT 후 질화의 심부 강도·치수 변화 영향을 설명할 것 |
| 고온 강도 | 실제 처리 상태에 적용되는 항복/0.2% 내력의 온도별 하한과 시험 조건 | 245–270°C 해석 범위를 포괄; 상온 시험의 뜨임 온도별 값과 구분 |
| 탄성·팽창 | E(T), ν, 열팽창계수 및 기준 온도/정의 | 평균 팽창계수와 순간 계수를 구분; 적용 범위 밖 외삽 금지 |
| 온도장 | 열전도율·비열과 적용 온도/처리 상태 | 국부 온도구배 계산의 입력으로 사용 가능한 근거 제시 |
| 치수 보증 | 최종 열처리 뒤 보어/축/센서 홀 검사와 공정능력 | 소스 도면의 최종 치수와 연결; 후보 치수를 승인값으로 오인하지 않을 것 |

현재 조건부 3D 센서 보어 모델은 6 MPa, 내면270°C/외면245°C에서 regional peak
49.935 MPa와 medium→fine 변화1.635%를 냈다. 따라서 이 모델에서 SF2에 필요한
최종 처리재의 245–270°C 항복/0.2% 내력 하한은99.869 MPa다. 이는 공급자 물성의
합격 문턱을 명확히 한 것이며, 가정된 온도장·형상·재료상수 때문에 실제 부품
qualification은 아니다.

배럴 센서 홀은 아직 깊이·선단 형상·프로브 고정 조건이 미폐쇄다.
기존 평바닥 CAD를 일반 드릴의 원추 끝 형상으로 임의 대체할 수 없다.
실제 가장 깊은 가공점과 원통부 깊이를 구분해 회신받아야 한다.

아래 값은 견적용 확정 도면이나 공급자 공정능력의 증거가 아니다.

프로브 선정 후 설계자가 접촉/안내·열응답·고온 국부 응력을 검증하고 도면을
개정해야 최종 공정 선택이 가능하다. 기존 단일 접점 열모델은 삽입 길이를
입력받지 않으므로 해당 모델의 PASS는 이 공정 선택의 승인 근거가 아니다.

## 유지판·체결부는 별도 확인

현재 후보는 중앙판4 mm와 일체형 뒤쪽 리브8 mm, M4×25 및4.20 mm 스페이서다.
후보의 STEP/해석은 `analysis/final_validation/results/v0.8/`에 있으며 출시 도면이 아니다.
SCM440 배럴 물성을 유지판이나 볼트에 자동 적용하지 않는다. 유지판 소재/상태,
볼트 강도 구분·나사 길이·유효 체결 길이·표면 처리·사용 온도 및 예압 관리
방법을 별도로 확정해야 한다. 볼트/접촉 모델에 넣을 강성은 이 자료와 실제
형상에서 유도하며, 현재10⁴–10⁶ N/mm 스프링 값은 민감도 가정일 뿐이다.

현재 후보 소스의 체결 치수 계산:

| 항목 | 명목 계산 | 해석 시 주의 |
|---|---|---|
| 머리 지지면→탭 입구 | (375.2−8)−355 = 12.2 mm | datum8 + spacer4.2; 볼트 탄성 유효 길이와 같다고 단정하지 않음 |
| 최소 완전나사 물림 | 8.0 mm = 2D | M4×0.7 pitch diameter 3.5453 mm, 모재 전단강도=177.5/√3 MPa 가정 |
| 볼트 끝 돌출 | (355+25)−(375.2+4) = 0.8 mm | 명목값; 길이 공차·끝 모따기·나사 불완전부 미반영 |

별도 Ø19 pilot 다이 후보의 6 MPa 압력 분리력은1737.18 N이다. 압력 분리에만
SF2를 적용하면 필요한 총 잔존 체결력은3474.35 N, 이상적인 4볼트 균등분담은
볼트당868.59 N이다. 여기에 gasket seating, preload scatter, 고온 relaxation과
prying은 포함되지 않았으므로 이 값을 조립 토크로 변환하거나 승인값으로 쓰지 않는다.

이 세 값은 현재 JSON의 retainer_front_x_mm/retainer_thickness_mm와 후보 소스의
머리 지지면 X355, 축 길이25, 리브8로 재계산하고 각각12.2/8.0/0.8 mm 일치를 확인했다.
구매품 회신에는 머리 밑 필렛, 실제 나사부 길이, 끝 불완전산과 길이 공차를 포함한다.
탭 입출구 모따기와 불완전산을 제외한 최소 완전산 겹침으로 나사산 파손을 평가해야 한다.
후보는 NASA RP-1228의 `P=π·d_m·F_s·L/3`으로 인발용량3043.8 N,
설계 볼트하중1241.3 N 대비 SF=2.452를 얻었다. 이는 모재가 실제 최고 사용온도에서
항복강도177.5 MPa 이상임을 성적서로 입증할 때만 유효하며 예압·prying/contact 판정은 아니다.
같은 문서의 `T=K·F·d`를 K=0.18–0.25에 적용한 설치 토크 후보2.8–3.0 N·m는
예압2800–4167 N, 최소 예압/설계하중=2.255, 최대 예압/proof load=0.818이다.
이는 건식 나사의 수치 screen일 뿐이며 실제 윤활·표면처리·열이완·재체결 절차가
확정되기 전에는 조립 토크로 채택하지 않는다.

## 회신 후 처리

1. 원본 자료와 판본·해당 제품/lot 연결을 보존하고 적용 가능성을 검토한다.
2. 부족한 온도/열처리 조건은 미확정으로 남긴다. 빈칸을 유사 강종 값으로 채우지 않는다.
3. 채택한 입력만 solver에 연결하고 열·압력·결합 하중 및 국부 모델을 재실행한다.
4. 도면/공차/조립 간섭을 갱신한 뒤 독립 검토와 전체 release gate를 다시 수행한다.

회신이나 성적서 자체가 조립체 안전 판정은 아니다. 실제 시험은 NOT_RUN이며,
구매·가공·통전에는 별도 사용자 승인이 필요하다. 현재 공급자에게 이 문서를
전송하지 않았고 비용을 발생시키지 않았다.
