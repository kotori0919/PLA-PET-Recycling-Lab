# 압출부 일관성·정밀도 확보 계획

기준: PPR `final-design-fabrication-closure-v0.8`. 이 문서는 디지털 오차 예산과 판정 기준의 보강이며 **실물 정밀도의 보증이 아니다.** 압출 직경 일관성은 P10-P12의 실측으로만 확정된다. 상태 어휘: OBSERVED(이번 실행), INFERRED(가정 포함 추론), PROPOSED(제안값), NOT_RUN.

## 1. 결론

- 설계만으로 "보장"할 수 있는 것은 없다. 대신 일관성을 깎는 요인을 계산으로 찾고, 실물에서 약속을 판정할 기준을 바로잡았다.
- 판정 기준의 허점을 발견해 고쳤다(2절). 이전 기준은 시료 평균과 타원도만 판정해 **시료 간 흩어짐(일관성)을 판정하지 않았다.**
- 직경 허용 ±0.03 mm(상대 ±1.7 %)는 질량 보존상 유량과 인취 속도의 변동 합이 약 ±3.4 %일 때의 한계다. 이 예산을 어느 요인이 얼마나 쓰는지 3절에 계산했다.
- 아직 미해결인 실물 입력(공급망, 열간 fit, 게이지 반복성, 인취 tach 분해능)은 4절에 남겼다.

## 2. 판정 기준의 허점과 수정 (OBSERVED)

이전 `analyze_material_run.py`는 20개 연속 안정 시료의 **평균 오차 <= 0.05 mm**, 시료별 **타원도 <= 0.05 mm**, **U95 <= 0.03 mm**를 확인했다. 이 U95는 시료별 측정 불확도이며 공정 흩어짐이 아니다. 그래서 1.72/1.78 mm를 번갈아 나오는 압출처럼 평균은 1.75이지만 크게 요동치는 결과도 통과할 수 있었다.

수정(PROPOSED 한계값, 기존 0.03 mm U95 예산에서 유도: U95 ~ 2 sigma):

| 기준 | 이전 | 수정 후 |
|---|---|---|
| 창 평균 오차 | <= 0.05 mm | <= 0.05 mm (유지) |
| 개별 시료 오차 | 없음 | 모든 시료 1.75 +/- 0.05 mm |
| 흩어짐 | 없음 | 시료 표준편차 <= 0.015 mm |
| 기준 게이지 U95 | <= 0.03 mm | <= 0.01 mm (측정 표준불확도를 sigma 예산의 1/3 이하로) |
| 타원도 | <= 0.05 mm | 유지 |

적용: P10/P11(`analyze_material_run.py`, 결과에 `diameter_sigma_mm`, `max_individual_error_mm` 추가), P12(`analyze_p12_records.py`에 `diameter_sigma` 지표 추가, `diameter_max_u95` 한계 0.01). 계약 `physical_gate_contract.json`, 실행 문서 P10_P11/P12, `product_specification_ko.md`, `templates/p12_forming_spool.csv`를 함께 갱신했다.

시험(OBSERVED, 모두 통과): `test_material_run` 9건(평균은 맞고 흩어짐이 큰 경우, 개별 이상치, 거친 기준 게이지를 거부하는 신규 4건 포함), `test_p12_execution` 6건(신규 1건), P10/P11 stage release 시험. 이 한계값(0.015, 0.01)은 제가 유도한 제안값이므로 사용자 검토 대상이다.

## 3. 오차 예산 (`analysis/extrusion_precision_v08/error_budget.py`, INFERRED)

원리: d = sqrt(4Q / (pi rho v)). 유량 Q 또는 인취 속도 v가 상대 x 변하면 직경은 x/2 변한다. 밀도는 문헌 가정(PLA 1.24, PET 1.33 g/cm3)이며 아래 결론은 비율이므로 밀도에 둔감하다. 다이 팽창·유변학은 모델에 없다.

| 항목 | 값 | 의미 |
|---|---|---|
| 허용 유량+속도 변동 (개별 +/-0.05) | 약 +/-5.7 % | 직경 +/-2.9 % |
| 허용 유량+속도 변동 (sigma 0.015) | 약 1.7 % | 흩어짐 한계 |
| 직경 민감도 | 1 %당 0.00875 mm | |
| 인취 속도 / 롤러 회전수 | PLA 9.26 mm/s, 4.4 rpm; PET 8.47 mm/s, 4.0 rpm | 40 mm 롤러에서 매우 느림 |
| 다이→게이지 이송 지연 | PLA 26.8 s, PET 29.3 s | 피드백이 늦다 |
| 인취 slip 1 % 한계의 직경 영향 | 0.00875 mm (개별 허용의 17.5 %) | slip 변동이 예산을 크게 쓴다 |
| 공급기 유량 편차(표면 모형 범위) 미보정 시 | +/-2.8 % -> 직경 +/-0.024 mm (개별 허용의 48 %) | 시계열이 아닌 케이스 간 수준 차이 |
| 스크류 용융 경로 지연(tau 약 122 s) 감쇠 | 주기 10 s 변동은 약 1.3 %로 감쇠, 600 s는 62 % | 빠른 맥동은 걸러지고 느린 드리프트는 통과 |
| 스크류-배럴 반경 틈새 0.01 mm | 처리량 1.5 %, 직경 0.013 mm | 정적 오프셋. 인취 설정으로 보정되고 마모 드리프트로 영향 |
| 피드백으로 못 막는 외란 주기 | 약 107 s 이하 | 이보다 빠른 외란은 근원에서 제한 |

시사점.
1. 정적 오차(부품 공차, 틈새)는 게이지 피드백이 보정한다. 일관성을 좌우하는 것은 동적 외란이다.
2. 피드백 지연이 27-29 s이므로 약 107 s보다 빠른 외란(인취 롤러 리플, slip 변동, 공급기 맥동)은 제어가 못 막는다. 근원에서 제한해야 한다.
3. 용융 경로가 빠른 공급기 맥동은 크게 걸러 주지만 수백 초 단위 드리프트는 못 거른다.
4. 인취 slip 한계와 롤러 런아웃이 예산을 직접 소모하므로 시험 전 계측 요구로 올렸다.

## 4. 도출된 요구와 미해결 항목

| ID | 요구 | 상태 |
|---|---|---|
| XP-01 | 기계 게이지와 독립인 기준 직경 계측기(분해능 0.001 mm), MSA %GRR이 0.10 mm 허용폭의 10 % 이하(<= 0.01 mm)임을 P10 전에 기록 | PROPOSED, 현재 반복성 기록 없음 |
| XP-02 | 인취 롤러 반경 런아웃 TIR <= 0.20 mm(속도 리플 0.5 % 배분)를 다이얼 게이지로 P12 전에 확인 | PROPOSED |
| XP-03 | 안정 구간 인취 slip 변동 <= 0.5 % (한계 1 %의 절반) | PROPOSED |
| XP-04 | P10-P12에서 공급기·스크류 전류·인취 속도를 1 Hz 이상 기록해 외란 주기를 분리 | PROPOSED |
| XP-05 | P6 전에 스크류 OD와 배럴 ID를 측정하고 세척 주기마다 반경 틈새 추적 | PROPOSED |
| XP-06 | 인취 속도 추정이 4.0-4.4 rpm에서 0.25 %를 분해해야 함. tach 펄스/회전은 현재 교정값으로 비어 있음 | **OPEN**: 실제 tach로 분해능을 확인하고, 부족하면 롤러 엔코더나 주기 타이머 캡처 추가 |

그 밖의 실물 미해결 입력: SCM440 스크류·배럴의 동일 heat Q&T·질화·후가공 공급망(JLCCNC 회신은 현 사양 전체 공정을 충족하지 않음, P5 coupon 선행), 열간 fit·잔류 예압·누설(P9/P10), 다이 팽창과 용융 유변학(미보정, 직경 목표 1.75 mm 대 다이 보어 3.0 mm), 직경 게이지(LED-포토다이오드 shadow)의 교정 불확도 U95 목표가 현재 0.03 mm로 직경 허용과 같은 크기라는 점(펌웨어는 U95 > 0.03 mm이면 제어를 끈다; 제어 허용 기준과 기준 계측 기준을 구분했다. 펌웨어 값은 이번에 바꾸지 않았다).

## 5. 실물에서 이 약속을 판정하는 경로

P5(공정 coupon: OD 15.90-15.92, ID 16.20 +0.02/0, 틈새 0.28-0.32 mm) -> P6(냉간 조립, 손 회전, 동축도 <= 0.05 mm) -> P9(빈 가열) -> P10(PLA)·P11(PET) 저속 공급 -> P12(성형·권취). P10-P12에서 20개 연속 안정 시료가 2절의 기준을 모두 만족해야 한다. 실패하면 합격 기준을 완화하지 않고 가장 이른 영향 단계로 돌아가 설계를 고친 뒤 같은 실물로 재시험한다.

## 6. 한계

이 문서의 수치는 질량 보존 1차 근사이며 용융 유변학, 다이 팽창, 냉각 수축을 포함하지 않는다. 실측으로 교정되기 전에는 성능 값으로 쓰지 않는다. 물리 시험은 전부 NOT_RUN이며 구매·가공·통전은 승인되지 않았다.
